# X-O Game

A simple Tic-Tac-Toe game built in Python. It supports:

- Two-player mode
- Player vs Computer mode
- Board reset and replay
- Win and draw detection
- Terminal-based interface

## Project Files

- `TicTacToe.py` - Main game logic
- `ironman.py` - Iron Man themed game variant

## How to Run

Open a terminal in the project folder and run:

```bash
python3 TicTacToe.py
```

## How to Play

1. Choose a game mode from the main menu.
2. Enter player names and symbols.
3. Select a board cell from 1 to 9.
4. Try to align three symbols in a row to win.

## Testing

Run the tests with:

```bash
pytest -q
```
